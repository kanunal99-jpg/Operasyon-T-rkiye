# Operasyon Türkiye

Mobil odaklı özgün 3D FPS savaş oyunu.

## İlk hedef
- Android dokunmatik kontrol
- 3D FPS kamera
- Ateş etme ve yeniden doldurma
- Yapay zekâ düşman
- Basit savaş arenası
- Can, mühimmat ve skor HUD

## Teknoloji
Godot 4.x / GDScript

Bu proje Call of Duty'nin kopyası değildir; özgün oyun mekaniği ve içerik geliştirme amacıyla oluşturulmaktadır.
